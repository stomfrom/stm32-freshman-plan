# P03 提示：GPIO 与按键：轮询去抖

## 知识点

1. GPIO 四种输入模式的区别：浮空输入（电平不定，必须有外部上下拉）、上拉输入、下拉输入、模拟输入。
2. 按键的两种常见接法：一端接 GND 一端接引脚（配内部上拉，按下为低）或一端接 VCC 一端接引脚（配内部下拉，按下为高）。
3. 机械抖动：金属触点在接触瞬间会弹跳，典型持续 0.5~5ms，表现为电平在短时间内高低乱跳。
4. 软件去抖的两种做法：延时确认法（检测到变化后等 20ms 再读一次）与非阻塞采样法（用时间戳记录上次变化，间隔够了才确认）。
5. 位运算读引脚：输入数据寄存器（IDR）的某一位就是引脚电平，用 `&` 取出、判断是否为 0。
6. 阻塞与不阻塞：`HAL_Delay` 期间整个程序停在原地，多个功能同时要跑的时候必须改成非阻塞。
7. 状态翻转的写法：用 `^=` 位运算翻转输出寄存器，或者用一个布尔变量记住状态再取反。

## 参考资源

1. 对应芯片参考手册的 GPIO 章节（重点看输入/输出模式与寄存器位定义）。
2. HAL 库 `HAL_GPIO_ReadPin` / `HAL_GPIO_TogglePin` 的 API 说明。
3. 开发板原理图中按键部分（找 KEY 或 BUTTON 标记的元件）。

## 常见坑

- **上拉/下拉配反**：结果是不按也一直算"按下"，或按了反而没反应；先用串口把原始电平打出来确认。
- **去抖延时给得太短**：比如只给 5ms，抖动还没结束就去读了，误触发照样有；一般 10~20ms 才稳。
- **按住不放被当成连续多次按下**：去抖逻辑只判断"变化"而不判断"是否已按下"，需要引入状态变量记录当前是否已按下。
- **一个按键接了两个引脚 / 引脚被别的外设占了**：CubeMX 会报冲突或者行为异常，先看引脚分配图。
- **LED 翻转写在按键按下分支里但没检查松手**：按住时会以主循环速度疯狂翻转，看起来像"乱闪"。

## 调试技巧（无逻辑分析仪时的替代手段）

- **串口打点是最直接的抖动探测器**：每次电平变化打一行带序号的时间戳，几毫秒内的连续多行就是抖动。
- **GPIO 翻转标记法**：在按键处理分支里翻转一个空闲引脚，示波器双通道同时看按键引脚和这个标记引脚，就能看出处理时机。
- **对着原理图核对接法**：先确认按键一端接的是地还是电源，比在代码里瞎改上下拉快得多。
- **万用表电压档实测**：程序跑起来后量按键引脚，一边按一边看读数是否在 0V 与 3.3V 之间切换。
