# P05 提示：定时器与 PWM：呼吸灯与舵机

## 知识点

1. 定时器的基本构成：时钟源 → 预分频器（PSC）→ 计数器（CNT）→ 自动重装寄存器（ARR）→ 溢出事件或中断。
2. 定时周期计算公式：`周期 = (PSC+1) × (ARR+1) / 定时器时钟频率`；反推参数时先定周期再定分频。
3. PWM 的原理：计数器与比较寄存器（CCR）比较，计数值小于 CCR 时输出一种电平，大于时输出另一种，比值就是占空比。
4. PWM 频率与占空比的关系：频率由 PSC 和 ARR 决定，占空比由 CCR 与 ARR 的比值决定，改占空比一般只动 CCR。
5. 舵机控制信号：周期 20ms 的 PWM，脉宽约 0.5ms 对应 0°、1.5ms 对应 90°、2.5ms 对应 180°（不同型号略有差异）。
6. 输入捕获：记录捕获到边沿时计数器的值，通过两次捕获值的差与计数频率换算出信号周期；用 PWM Input 模式时 CH1 测周期、CH2 测脉宽。
7. 中断里"只计数不处理"的模式：中断负担极轻，耗时任务交给主循环按计数判断，避免中断时间过长。
8. 预分频与重装都是 16 位，算参数时注意不要超出范围，也不要把频率算到超出实际可用范围。

## 常见坑

- **PWM 输出没有任何波形**：忘记调用 `HAL_TIM_PWM_Start`，或通道配成了别的复用功能，或引脚被 CubeMX 分给了别的外设。
- **预分频/重装值算错导致频率差十倍**：忘了公式里是 `(PSC+1)`、`(ARR+1)`，也忘了确认定时器挂在哪个总线（APB1 与 APB2 频率可能不同）。
- **同一定时器不同通道想跑不同频率**：物理上不可能，ARR 是每定时器一个——后写的 ARR 会覆盖先写的，两路必然同频；要不同频率必须换定时器（同一个 TIM 的两个通道只能同频）。
- **`HAL_RCC_GetPCLK1Freq()` 是 36MHz，定时器时钟是它 ×2**：默认时钟树下 PCLK1 = SYSCLK/2 = 36MHz，APB1 定时器时钟 = PCLK1×2 = 72MHz；别拿 `HAL_RCC_GetPCLK1Freq()` 的返回值直接当定时器时钟，否则会以为时钟树配错了（可打印 `SystemCoreClock` 与 `HAL_RCC_GetPCLK1Freq()*2` 对照）。
- **改占空比没反应**：改的是 ARR 而不是 CCR，或者改的通道号不对。
- **舵机抖动或不动**：供电不足（不要用开发板 3.3V 直接带舵机，需要独立 5V 供电且共地），或 PWM 频率不是 50Hz。
- **电机启动时单片机复位**：电机电流冲击拉低电源，需要独立供电并加去耦电容。
- **计数器溢出导致计时跳变**：计数器是 16 位会回绕，做长时间累计时要处理回绕（用差值计算而不是直接比较）。

## 调试技巧（无逻辑分析仪时的替代手段）

- **示波器直接看 PWM**：这是本项目最该用示波器的场景，测频率、测占空比、量脉宽，一目了然。
- **引脚翻转计时法**：在定时器中断里翻转一个空闲引脚，用示波器看它的周期，就能验证定时器实际中断频率对不对。
- **计数打印法**：把定时器计数值周期性打印出来，看它是否稳定增长，据此判断分频参数是否合理。
- **信号源自检**：用另一个 GPIO 或板上已有信号（如 LED 翻转引脚）作为输入捕获的信号源，先验证测量链路通不通。
