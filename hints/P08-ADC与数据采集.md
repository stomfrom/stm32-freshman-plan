# P08 提示：ADC 与数据采集：滤波与标定

## 知识点

1. ADC 的核心参数：分辨率（12 位对应 0~4095）、参考电压（决定换算比例）、采样时间（源阻抗大时要加长）。
2. 换算公式：`电压 = 原始值 × 参考电压 / 满量程`；参考电压是 3.3V 时，1 个计数约等于 0.8mV。
3. 输入范围限制：ADC 引脚电压不能超过参考电压，超过会损坏引脚或读满值，输入前要确认分压比例。
4. 采样时间与源阻抗的关系：信号源内阻越大，采样电容充电越慢，采样时间设太短会导致读数偏低。
5. 滑动平均滤波：维护一个窗口，新数据进、老数据出，对周期性噪声效果好，代价是响应变慢。
6. 中值滤波：对一组样本排序取中间值，对突发性尖峰干扰（比如开关瞬间的毛刺）效果好。
7. 两点标定：用两个已知标准点求出 `y = kx + b` 的 k 与 b，把原始读数换算成实际物理量，比理论公式更准。
8. Flash 存储的三个要点：写入前必须先擦除（按扇区擦）、擦除后位变成 1、写入只能把 1 变成 0；擦写寿命有限，不要频繁写。

## 参考资源

1. 对应芯片参考手册的 ADC 章节（重点看通道选择、采样时间、参考电压、校准）。
2. HAL 库 `HAL_ADC_Start_DMA` / `HAL_ADC_PollForConversion` 的 API 说明。

## 常见坑

- **读数一直在满量程附近**：输入电压超过参考电压，或引脚配成了输出模式，或该引脚被别的外设占用。
- **读数飘得厉害、跳动几十个计数**：地线没接好、信号源内阻大且采样时间太短、电源本身有纹波；先加滤波再看是否需要改硬件。
- **多通道采样串道（数据对不上通道）**：DMA 传输的数据顺序与通道配置顺序不一致，或通道切换后没有等待稳定就采样。
- **忘记做 ADC 校准**：部分芯片需要先执行校准流程，不校准会导致读数有固定偏差，表现为"怎么都对不上万用表"。
- **Flash 写入后读不回来**：写之前没擦除（旧数据把新数据挡住了），或者写地址不是扇区对齐的。
- **频繁写 Flash 把扇区写坏**：每次采样都写 Flash；应该攒一批再写，或做磨损均衡。

## 调试技巧（无逻辑分析仪时的替代手段）

- **原始值先打印，别急着换算**：原始计数是判断 ADC 工作是否正常的最直接依据，先确认原始值随输入变化再谈公式。
- **万用表当标准源对照**：一个一个点地对，比看曲线更可靠，能立刻发现是固定偏差（系数问题）还是随机波动（噪声问题）。
- **输入接固定分压自检**：用两个电阻分压产生一个已知电压接进去，先验证采集链路，再上真实传感器。
- **滤波效果量化**：把滤波前后各 100 个数据的最大最小值打出来，差值就是波动幅度，用数字比用眼睛看更准。
