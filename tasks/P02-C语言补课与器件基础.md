## 任务

> 📖 每条任务后面都带 **教程** 链接，点击直达手把手教程（含知识点详解、完整操作步骤、可复制代码）。

### A 档 · 全员必做（通关底线）

- [ ] 1. 用数组重写 LED 闪烁程序：把 8 个不同的延时值存进数组，主循环依次取用，让闪烁变成 8 种不同节奏。 [📖 教程](../tutorials/P02-C语言补课与器件基础.md#p02-a1)
- [ ] 2. 把「点亮」「熄灭」「翻转」三种 LED 操作各封装成一个函数，主循环只调用函数，不直接写寄存器或 HAL 调用。 [📖 教程](../tutorials/P02-C语言补课与器件基础.md#p02-a2)
- [ ] 3. 用一个结构体描述 LED 对象（成员含引脚号、当前状态），并为它写 `led_init` 与 `led_blink` 两个函数，在程序里实际用起来。 [📖 教程](../tutorials/P02-C语言补课与器件基础.md#p02-a3)
- [ ] 4. 写出 `BIT_SET` / `BIT_CLEAR` / `BIT_TOGGLE` / `BIT_READ` 四个位运算宏，用它们管理一个软件位标志字节（如 `led_flags`），用 `BIT_READ` 逐位读出并打印；再用 `GPIOx->ODR` 或 `BSRR` 直写一次 LED，对比与 `HAL_GPIO_WritePin` 的效果差异。 [📖 教程](../tutorials/P02-C语言补课与器件基础.md#p02-a4)
- [ ] 5. 用串口打印出上面用到的数组内容与结构体成员值，确认打印结果与预期一致。 [📖 教程](../tutorials/P02-C语言补课与器件基础.md#p02-a5)

### B 档 · 全员必做（能力上限）

- [ ] 1. 用 `printf` 输出一张格式化的表格：每秒打印一行（运行秒数 / LED 状态 / 按键电平），要求列对齐；**不做接收与命令解析**——串口接收和命令表单在 P06 学。 [📖 教程](../tutorials/P02-C语言补课与器件基础.md#p02-b1)
- [ ] 2. 写一个求平均值的函数，参数用指针接收数组，计算并返回平均值，在串口上打印结果。 [📖 教程](../tutorials/P02-C语言补课与器件基础.md#p02-b2)
- [ ] 3. 用万用表的直流电压档，实测开发板上 3.3V 与 5V 引脚的实际电压，记录两组读数。 [📖 教程](../tutorials/P02-C语言补课与器件基础.md#p02-b3)
- [ ] 4. 用万用表的电阻档测出板载 LED 限流电阻的阻值，与开发板原理图上标注的值对比，记录偏差。 [📖 教程](../tutorials/P02-C语言补课与器件基础.md#p02-b4)
- [ ] 5. 用万用表的通断档，验证一条杜邦线从一端到另一端是通的、两根不相干的线之间是不通的，记录测试结果。 [📖 教程](../tutorials/P02-C语言补课与器件基础.md#p02-b5)

## 交付物

1. 源码 / 设计文件：P02 工程源码（含位运算宏定义头文件）、个人仓库提交记录。
2. 实测证据：串口表格输出截图、万用表电压与电阻读数照片（含表笔位置）、通断测试记录。
3. README：说明 8 个延时值的含义、结构体与函数的设计思路、实测读数与原理图标注值的对比结论。
4. 验收自测清单：逐条勾选任务并附证据文件名。

## 验收标准

- `BIT_SET` / `BIT_CLEAR` / `BIT_TOGGLE` / `BIT_READ` 四个宏都在程序里被真实调用过（能在源码里指出调用位置），不能只写在头文件里没用；另需完成一次 `GPIOx->ODR` 或 `BSRR` 直写并与 `HAL_GPIO_WritePin` 对比。
- 串口表格输出列对齐，每秒一行；运行秒数递增、LED 状态与按键电平与实际一致。
- 万用表电压读数与开发板标注值偏差在 ±5% 以内；若超出，能在 README 里给出至少 1 种可能原因。
- 电阻读数与原理图标注值的对比结论有明确记录（是吻合还是偏差多少）。
- 工程重新编译通过，0 错误。
