# P02 C 语言补课与器件基础：串口 + 万用表

| 项目编号 | P02 | 周期 | 2 周 |
|---|---|---|---|
| 学期 | 秋季 slot 2 | 起止日期 | 2026-09-28 ~ 2026-10-11 |
| 难度 | ★★ | 适用 | A、B 两档全员必做 |

## 前置要求

- 完成 P01，能独立新建工程、编译下载，并让 LED 闪烁。

## 任务

### A 档 · 全员必做（保底）

- [ ] 1. 用数组重写 LED 闪烁程序：把 8 个不同的延时值存进数组，主循环依次取用，让闪烁变成 8 种不同节奏。
- [ ] 2. 把「点亮」「熄灭」「翻转」三种 LED 操作各封装成一个函数，主循环只调用函数，不直接写寄存器或 HAL 调用。
- [ ] 3. 用一个结构体描述 LED 对象（成员含引脚号、当前状态），并为它写 `led_init` 与 `led_blink` 两个函数，在程序里实际用起来。
- [ ] 4. 写出 `SET_BIT` / `CLEAR_BIT` / `TOGGLE_BIT` / `READ_BIT` 四个位运算宏，并用这 4 个宏改写任务 2 的三个函数，确认功能不变。
- [ ] 5. 用串口打印出上面用到的数组内容与结构体成员值，确认打印结果与预期一致。

### B 档 · 全员必做（进阶）

- [ ] 1. 在串口上做一个简单命令表单：收到 `led_on` 就点亮、`led_off` 就熄灭、`blink 5` 就闪 5 次，不认识的命令回一行提示。
- [ ] 2. 写一个求平均值的函数，参数用指针接收数组，计算并返回平均值，在串口上打印结果。
- [ ] 3. 用万用表的直流电压档，实测开发板上 3.3V 与 5V 引脚的实际电压，记录两组读数。
- [ ] 4. 用万用表的电阻档测出板载 LED 限流电阻的阻值，与开发板原理图上标注的值对比，记录偏差。
- [ ] 5. 用万用表的通断档，验证一条杜邦线从一端到另一端是通的、两根不相干的线之间是不通的，记录测试结果。

## 交付物

1. 源码 / 设计文件：P02 工程源码（含位运算宏定义头文件）、个人仓库提交记录。
2. 实测证据：串口命令执行截图、万用表电压与电阻读数照片（含表笔位置）、通断测试记录。
3. README：说明 8 个延时值的含义、结构体与函数的设计思路、实测读数与原理图标注值的对比结论。
4. 验收自测清单：逐条勾选任务并附证据文件名。

## 验收标准

- 4 个位运算宏都在程序里被真实调用过（能在源码里指出调用位置），不能只写在头文件里没用。
- 串口命令表单能正确响应 3 条以上命令，收到错误命令时不会卡死或乱码。
- 万用表电压读数与开发板标注值偏差在 ±5% 以内；若超出，能在 README 里给出至少 1 种可能原因。
- 电阻读数与原理图标注值的对比结论有明确记录（是吻合还是偏差多少）。
- 工程重新编译通过，0 错误。
