- [ ] 2. 实现「按下按键点亮 LED、松开熄灭」，确认按下与松开的动作各触发一次正确结果。 [📖 教程](../tutorials/P03-GPIO与按键.md#p03-a2)

- [ ] 4. 用位运算宏直接操作 GPIO 的输入数据寄存器读按键电平（不调用 HAL 读函数），确认读到的值与 HAL 方式一致。 [📖 教程](../tutorials/P03-GPIO与按键.md#p03-b4)

## 交付物

1. 源码 / 设计文件：P03 工程源码（含按键读取与去抖模块）、原理图截图（标注按键与上下拉电阻）。
2. 实测证据：按键电平序列串口日志、100 次按压统计表、抖动波形截图（或打点日志）。
3. README：按键引脚号、上/下拉接法、去抖参数（延时值或采样间隔）的选择依据、与 HAL 读法的对比结论。
4. 验收自测清单：逐条勾选任务并附证据文件名。

## 验收标准

- 连续按压 100 次，误触发次数 ≤ 2 次。
- 按住不放时 LED 状态不反复跳变（说明去抖有效、且没有把持续按住误判成多次按下）。
- 非阻塞版本的 `main` 主循环里不存在 `HAL_Delay` 之类的阻塞延时（能在源码里指出来）。
- 串口电平日志能清楚看出每次按下对应的电平变化行，序号连续无缺号。
- 能对着原理图讲清按下与松开的电平变化原因，不需要看答案。
