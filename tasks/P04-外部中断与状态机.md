# P04 外部中断与状态机：短按/长按/双击

|---|---|---|---|
| 学期 | 秋季 slot 4 | 起止日期 | 2026-10-26 ~ 2026-11-08 |
| 难度 | ★★★ | 适用 | A、B 两档全员必做 |

## 前置要求

- 完成 P03，能独立完成按键读取与去抖，能在源码里指出 `main` 主循环是否有阻塞延时。

## 任务

### A 档 · 全员必做（保底）

- [ ] 1. 把按键改成外部中断触发（下降沿），并在 CubeMX 里使能对应的 EXTI 中断与 NVIC。
- [ ] 2. 在中断服务函数里只置一个标志位，其余判断与动作全部放到主循环里执行。
- [ ] 3. 用 `HAL_GetTick()` 做时间戳，判断按下持续时间，区分短按（<500ms）与长按（≥1s）两种事件。
- [ ] 4. 在串口上输出每次事件的类型（短按/长按）与当时的时间戳，连续操作 20 次核对。
- [ ] 5. 画出状态机状态转移图：标出每个状态、每个状态的进入条件与退出条件（手绘拍照或画图工具均可）。

### B 档 · 全员必做（进阶）

- [ ] 1. 加入双击判定：两次短按间隔 <300ms 判定为双击，输出第三种事件类型。
- [ ] 2. 做一张 50 次连续操作的记录表，记录每次的实际动作与程序判定结果，统计误判次数。
- [ ] 3. 用定时器时基（而不是 `HAL_GetTick`）驱动状态机，说明两种时间基准的差别与各自适用场景。
- [ ] 4. 把状态机写成独立的 `key.c` / `key.h` 模块，对外只暴露"取事件"一个接口，主循环不再直接碰 GPIO。
- [ ] 5. 在 README 里说明中断与主循环共享的那个标志变量存在什么风险，以及你用什么办法避免了它（如暂时关中断、或用原子读写）。

## 交付物

1. 源码 / 设计文件：P04 工程源码（按键模块 .c/.h 分离）、状态转移图、50 次操作记录表。
2. 实测证据：串口事件日志（含时间戳）、双击与长按的实测视频或截图。
3. README：状态机的状态定义、各时间阈值取值与理由、时间基准选择说明、共享数据风险的处理方式。
4. 验收自测清单：逐条勾选任务并附证据文件名。

## 验收标准

- 短按、长按、双击三种事件在 50 次连续操作中的判定正确率 ≥ 96%（允许 ≤2 次误判，且能解释原因）。
- 中断服务函数内不存在任何 `HAL_Delay` 或长时间循环（能在源码里指出）。
- 长按事件在按住期间只上报一次，不重复上报。
- 快速连按（每秒 3 次以上）时不丢事件、不重复计数。
- 状态转移图与实际代码逻辑一致（评审时能照着图讲清代码分支）。
