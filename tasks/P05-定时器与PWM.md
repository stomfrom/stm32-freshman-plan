## 任务

> 📖 每条任务后面都带 **教程** 链接，点击直达手把手教程（含知识点详解、完整操作步骤、可复制代码）。

### A 档 · 全员必做（通关底线）

- [ ] 1. 配置一个定时器为 1ms 周期中断（预分频 + 自动重装值自己算），中断里累加一个计数器。 [📖 教程](../tutorials/P05-定时器与PWM.md#p05-a1)
- [ ] 2. 用这个计数器实现"每秒串口打印一次累计运行秒数"，连续运行 10 分钟核对计时是否准确。 [📖 教程](../tutorials/P05-定时器与PWM.md#p05-a2)
- [ ] 3. 配置一个 PWM 输出通道，用改变占空比的方式实现 LED 呼吸灯（渐亮渐暗连续循环）。（板载 PC13 无定时器通道，需外接 LED 到 PA6 + 1kΩ） [📖 教程](../tutorials/P05-定时器与PWM.md#p05-a3)
- [ ] 4. 用示波器实测 PWM 波形的频率与占空比，把实测值和 CubeMX 里配置的理论值都记录下来并对比。（无示波器时用另一路输入捕获自测，见教程） [📖 教程](../tutorials/P05-定时器与PWM.md#p05-a4)
- [ ] 5. 把定时器参数（PSC、ARR、目标频率、所属定时器与通道）写成注释或结构体，说明每个值是怎么算出来的。 [📖 教程](../tutorials/P05-定时器与PWM.md#p05-a5)

### B 档 · 全员必做（能力上限）

- [ ] 1. 用 PWM 控制一个舵机，让它依次转到 0°、90°、180° 三个位置，用示波器测出每个位置对应的脉宽。 [📖 教程](../tutorials/P05-定时器与PWM.md#p05-b1)
- [ ] 2. 用 PWM 驱动直流电机或小风扇实现 3 档调速（慢/中/快），在串口上用命令切换档位。 [📖 教程](../tutorials/P05-定时器与PWM.md#p05-b2)
- [ ] 3. 用定时器的输入捕获功能（PWM Input 模式，CH1 测周期、CH2 测脉宽）测一个外部方波信号的频率，把测量值与信号源设定值对比，记录误差。 [📖 教程](../tutorials/P05-定时器与PWM.md#p05-b3)
- [ ] 4. 用两个定时器各驱动一路不同频率的 PWM（如 TIM3 CH1 1kHz + TIM4 CH2 10kHz），把配置抽成参数表，加一路只改表不改逻辑。 [📖 教程](../tutorials/P05-定时器与PWM.md#p05-b4)
- [ ] 5. 用定时器做一个更精细的时基：把 A 档的 1ms 中断改成"仅计数、不做任何处理"，主循环判断计数器到点再执行任务，说明这样做的好处。 [📖 教程](../tutorials/P05-定时器与PWM.md#p05-b5)

## 交付物

1. 源码 / 设计文件：P05 工程源码（定时器与 PWM 配置模块）、定时器参数计算过程（预分频/重装值推导）。
2. 实测证据：示波器 PWM 波形截图（标注频率与占空比）、舵机三个角度位置照片、计时核对记录、输入捕获误差记录。
3. README：定时器参数计算公式、PWM 频率与占空比的实测对比结论、舵机脉宽与角度的对应关系。
4. 验收自测清单：逐条勾选任务并附证据文件名。

## 验收标准

- 定时器计时 10 分钟与手机秒表对比，误差 ≤ 2 秒。
- 示波器实测 PWM 频率与配置值偏差 ≤ 5%，占空比偏差 ≤ 3%。
- 呼吸灯渐变肉眼可见连续，无跳变、无卡顿。
- 舵机能稳定停在 0°/90°/180° 三个位置，重复来回 10 次不跑偏。
- 输入捕获测频结果与信号源设定值的误差有明确记录（在 README 里写出误差百分比）。
