### A 档 · 全员必做（通关底线）

- [ ] 1. 实现串口收发字符串：串口助手发什么，单片机就原样回什么（回显），连续收发 30 次正确。 [📖 教程](../tutorials/P06-UART与自定义协议.md#p06-a1)
- [ ] 2. 在 P01 的 `fputc` 重定向基础上，把日志输出封装成 `log_printf(level, fmt, ...)`（level = INFO/WARN/ERROR），输出格式统一为 `[INFO] 12.345s: xxx`，并说明为什么不直接到处 `printf`。 [📖 教程](../tutorials/P06-UART与自定义协议.md#p06-a2)
- [ ] 3. 定义一帧数据格式（帧头 + 长度 + 命令码 + 数据 + 校验），把格式写成一张表放进 README。 [📖 教程](../tutorials/P06-UART与自定义协议.md#p06-a3)
- [ ] 4. 用状态机逐字节解析收到的数据：按帧头同步、按长度收齐、校验通过才算一帧有效，收到有效帧后回一帧应答。 [📖 教程](../tutorials/P06-UART与自定义协议.md#p06-a4)
- [ ] 5. 构造 5 种异常输入（帧头错、长度错、校验错、半帧、超长帧）并逐一验证：程序不崩溃、能丢弃错误帧并继续接收。 [📖 教程](../tutorials/P06-UART与自定义协议.md#p06-a5)

### B 档 · 全员必做（能力上限）

- [ ] 1. 把简单校验和升级成 CRC 校验（CRC8 或 CRC16），校验失败时丢弃该帧并把错误计数加一。 [📖 教程](../tutorials/P06-UART与自定义协议.md#p06-b1)
- [ ] 2. 用串口接收中断 + 环形缓冲区处理不定长数据，连续发送 100 帧，记录丢包数与错帧数。 [📖 教程](../tutorials/P06-UART与自定义协议.md#p06-b2)
- [ ] 3. 把协议按层拆分（物理层收发 / 帧解析层 / 命令处理层），在 README 里画出分层图并说明每层职责。 [📖 教程](../tutorials/P06-UART与自定义协议.md#p06-b3)
- [ ] 4. 写一份《协议说明文档》，包含帧格式表、命令码含义、校验算法说明，让另一位同学照着能实现出双方的通信。 [📖 教程](../tutorials/P06-UART与自定义协议.md#p06-b4)
- [ ] 5. 实现"命令回显应答"以外的第二种交互：单片机主动周期性上报一帧状态数据（含运行秒数与 LED 状态）。 [📖 教程](../tutorials/P06-UART与自定义协议.md#p06-b5)

## 交付物

1. 源码 / 设计文件：P06 工程源码（协议模块 .c/.h 分离）、帧格式表、协议说明文档、分层结构图。
2. 实测证据：回显测试记录、100 帧连续收发的丢包统计表、5 种异常输入的验证记录（截图或日志）。
3. README：帧格式设计理由、CRC 参数选择、分层设计说明、压力测试结论。
4. 验收自测清单：逐条勾选任务并附证据文件名。

## 验收标准

- 连续发送 100 帧，丢包数 ≤ 1，错帧能被正确识别并计数，程序全程不重启、不卡死。
- 5 种异常输入全部被正确丢弃，且丢弃后能继续正常接收后续正确帧（不出现"一旦错就再也不工作"）。
- 协议说明文档由另一位同学照着实现后能正常互通（评审时演示这一验证过程）。
- 源码中可见明确的层间调用关系：命令处理层不直接操作串口寄存器。
- 主动上报的帧间隔稳定，连续观察 30 帧时间间隔偏差 ≤ 10%。
