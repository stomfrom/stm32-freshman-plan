## 任务

> 📖 每条任务后面都带 **教程** 链接，点击直达手把手教程（含知识点详解、完整操作步骤、可复制代码）。

### A 档 · 全员必做（通关底线）

- [ ] 1. 配置硬件 I2C（速率 100kHz 或 400kHz），用 I2C 扫描程序遍历地址段，把总线上所有响应设备地址打印出来。 [📖 教程](../tutorials/P07-I2C与传感器.md#p07-a1)
- [ ] 2. 用硬件 I2C 驱动一块 OLED 屏，在屏上显示一行英文字符串。驱动代码直接用教程附录 A（SSD1306 / I2C / 7 位地址 0x3C），不要从网上另找，接口不一致会白屏。 [📖 教程](../tutorials/P07-I2C与传感器.md#p07-a2)
- [ ] 3. 在 OLED 上显示一个每秒自增的计数器，连续观察 1 分钟不出现花屏、跳字或卡死。 [📖 教程](../tutorials/P07-I2C与传感器.md#p07-a3)
- [ ] 4. 把 OLED 的显示内容通过串口同步打印一份，两份内容保持一致（用于离线核对）。 [📖 教程](../tutorials/P07-I2C与传感器.md#p07-a4)
- [ ] 5. 在 README 里写清使用的 I2C 引脚号、从机地址、上拉电阻的位置与阻值。 [📖 教程](../tutorials/P07-I2C与传感器.md#p07-a5)

### B 档 · 全员必做（能力上限）

- [ ] 1. 在 OLED 上做一个多页菜单：至少 3 个页面，用按键上下翻页、当前选中项高亮显示。 [📖 教程](../tutorials/P07-I2C与传感器.md#p07-b1)
- [ ] 2. 用示波器抓 SDA 与 SCL 波形，在图上标出起始条件、地址字节、ACK 位、停止条件各在哪一段。 [📖 教程](../tutorials/P07-I2C与传感器.md#p07-b2)
- [ ] 3. 把 OLED 驱动封装成独立模块（`.c` / `.h` 分离，对外只暴露 `oled_init`、`oled_print`、`oled_clear` 等接口），主程序里不出现任何 I2C 底层调用。 [📖 教程](../tutorials/P07-I2C与传感器.md#p07-b3)
- [ ] 4. 做一个"换屏测试"：修改驱动模块里的初始化序列与分辨率参数，适配另一款不同驱动芯片的 OLED（或说明若换成 SPI 接口的屏需要改哪几处；纸上分析即可，不必真买第二块屏）。 [📖 教程](../tutorials/P07-I2C与传感器.md#p07-b4)
- [ ] 5. 在 I2C 总线上再接一个**温湿度传感器**（AHT20，7 位地址 `0x38`；或 SHT30 `0x44`），读出温度与湿度显示到 OLED 上，每秒刷新一次；并做超限告警（如温度 > 30℃ 时屏上显示 `ALERT`）。 [📖 教程](../tutorials/P07-I2C与传感器.md#p07-b5)

## 交付物

1. 源码 / 设计文件：P07 工程源码（OLED 驱动模块独立成文件）、I2C 引脚与地址说明、示波器波形标注图。
2. 实测证据：I2C 扫描结果截图、OLED 显示照片（含计数与菜单）、1 分钟连续运行视频或连拍、SDA/SCL 波形截图、温湿度读数截图与对应串口日志、超限告警（`ALERT`）截图。
3. README：I2C 参数、从机地址、上拉电阻说明、驱动模块的对外接口列表、换屏需要改动的位置、温湿度传感器的地址与换算公式。
4. 验收自测清单：逐条勾选任务并附证据文件名。

## 验收标准

- I2C 扫描能正确列出总线上实际存在的设备地址，不漏报、不多报（接上温湿度传感器后应同时出现 `0x3C` 与 `0x38`）。
- OLED 内容刷新稳定：连续运行 1 分钟无花屏、无残留、无卡死。
- 菜单翻页响应按键 ≤ 200ms，选中高亮与实际设置项一致，翻到最后一页再翻能回到第一页。
- 主程序的源文件里不出现 I2C 底层读写调用（只在驱动模块里出现），能在评审时指出这一点。
- 示波器波形图上能正确指出起始条件、地址、ACK、停止条件四个位置。
- 温湿度传感器读数与串口打印一致，误差 ≤ 0.5℃；温度超限时 OLED 上出现 `ALERT`。
