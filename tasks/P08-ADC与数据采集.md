### A 档 · 全员必做（通关底线）

- [ ] 1. 配置一个 ADC 通道（注意参考电压与分辨率设置），用轮询方式单次采样并通过串口打印原始值。 [📖 教程](../tutorials/P08-ADC与数据采集.md#p08-a1)
- [ ] 2. 把 ADC 原始值按公式换算成实际电压（单位 mV）并打印，同时打印原始值便于对照。 [📖 教程](../tutorials/P08-ADC与数据采集.md#p08-a2)
- [ ] 3. 用万用表测量同一路输入的实际电压，与程序算出的电压值对比，记录偏差。 [📖 教程](../tutorials/P08-ADC与数据采集.md#p08-a3)
- [ ] 4. 转动电位器（或用电阻分压）改变输入电压，观察程序读数随之连续变化，记录 5 个不同输入点的读数。 [📖 教程](../tutorials/P08-ADC与数据采集.md#p08-a4)
- [ ] 5. 把采样与换算封装成独立模块（`.c` / `.h`），对外提供"读一次电压"的接口，主程序只调用接口。 [📖 教程](../tutorials/P08-ADC与数据采集.md#p08-a5)

### B 档 · 全员必做（能力上限）

- [ ] 1. 配置 ADC + DMA 做多通道连续采样（至少 2 个通道），在串口上按通道分组打印数据。 [📖 教程](../tutorials/P08-ADC与数据采集.md#p08-b1)
- [ ] 2. 实现两种数字滤波（滑动平均、中值滤波），把滤波前后的数据都记录下来，画出或列表对比两条曲线的差别。 [📖 教程](../tutorials/P08-ADC与数据采集.md#p08-b2)
- [ ] 3. 做两点标定：用两个已知的输入值（如 0.5V 与 2.5V）求出线性换算系数，用第三个已知点验证换算误差。 [📖 教程](../tutorials/P08-ADC与数据采集.md#p08-b3)
- [ ] 4. 把采样数据保存到单片机内部 Flash：存一段数据、断电、重新上电后能读回，并说明写入前为什么要先擦除。 [📖 教程](../tutorials/P08-ADC与数据采集.md#p08-b4)
- [ ] 5. 用 OLED（P07 的驱动模块）把实时电压值显示出来，实现"采集 + 显示"联动，刷新不闪屏。 [📖 教程](../tutorials/P08-ADC与数据采集.md#p08-b5)

## 交付物

1. 源码 / 设计文件：P08 工程源码（ADC 采集模块 + 滤波模块 + Flash 存储模块）、5 个输入点的实测记录表、标定系数推导过程。
2. 实测证据：串口原始值与电压值对照日志、万用表实测照片、滤波前后数据对比、断电重上电读回数据的证据。
3. README：ADC 配置参数、换算公式、滤波算法说明与对比结论、标定结果与验证误差、Flash 读写注意事项。
4. 验收自测清单：逐条勾选任务并附证据文件名。

## 验收标准

- 程序算出的电压与万用表实测值偏差 ≤ 3%（在 0.3V~3.0V 范围内至少验证 3 个点）。
- 5 个不同输入点的读数单调变化，不出现跳变或负值。
- 两种滤波前后的对比有明确数据：滤波后数据波动幅度明显小于滤波前（列出波动幅度数值）。
- 两点标定后用第三个点验证，换算误差 ≤ 5%。
- 断电重上电后能从 Flash 读回先前写入的数据，内容与写入时一致。
- OLED 显示刷新时无明显闪屏（连续观察 30 秒）。
