# P10 独立选题结课项目：完整作品

| 项目编号 | P10 | 周期 | 4 周 |
|---|---|---|---|
| 学期 | 春季 slot 7-8 | 起止日期 | 2027-05-24 ~ 2027-06-20 |
| 难度 | ★★★★★ | 适用 | A、B 两档全员必做 |

## 前置要求

- 完成 P01~P09，至少独立完成过 7 个项目的验收；能自己查资料、自己定位问题。

## 任务

### A 档 · 全员必做（保底）

- [ ] 1. 自选一个题目（如温湿度显示仪、倒计时器、简易电子琴、智能小灯、按键密码锁等），写一页需求说明：做什么、给谁用、至少要有什么功能。
- [ ] 2. 列出所需器件清单（元件名称 + 型号 + 数量 + 用途），交给指导人确认后再动手。
- [ ] 3. 画出接线图或原理图（手绘拍照、画图工具、嘉立创 EDA 均可），标出每个引脚接什么。
- [ ] 4. 完成程序编写与调试，做出一个能现场演示的成品（上电即可工作，不依赖电脑里的调试器）。
- [ ] 5. 至少实现 3 类来自前面项目的外设功能（如按键 + 显示 + 通信，或 ADC + PWM + 串口）。
- [ ] 6. 提交完整的四件套，并在评审时做 10 分钟讲解：需求 → 方案 → 遇到的最大难点 → 如果重做会改什么。

### B 档 · 全员必做（进阶）

- [ ] 1. 写出系统框图，标出各模块之间的数据流向（谁产生数据、谁消费、通过什么方式传递）。
- [ ] 2. 做到模块化：至少把 2 个功能封装成独立的 `.c` / `.h` 模块，模块对外接口清晰、应用层不碰底层寄存器。
- [ ] 3. 为成品写一份使用说明（怎么接电、怎么操作、每个按键或每步操作的效果），让别人不看代码也能用起来。
- [ ] 4. 做一次异常场景测试：断电重上电、按键连按、输入超范围等至少 3 种情况，记录现象并说明处理方式。
- [ ] 5. 在 `PITFALLS.md` 里补至少 2 条自己在结课项目中踩过的坑，写清现象与解决办法。
- [ ] 6. 在评审中回答随机追问：随便挑一段代码讲清它的作用、随机改一个小需求说明你要改哪几个文件。

## 交付物

1. 源码 / 设计文件：完整工程源码、模块划分的 `.c` / `.h` 文件、接线图或原理图、需求说明一页纸。
2. 实测证据：成品工作视频（含操作演示）、异常场景测试记录、断电重上电可正常工作的证据。
3. README：系统框图、模块划分与接口说明、器件清单与用途、最大难点与解决过程、重做会改什么。
4. 验收自测清单：逐条勾选任务并附证据文件名；使用说明单独一份。

## 验收标准

- 成品上电即可工作，不接电脑、不依赖调试器，连续运行 15 分钟功能正常。
- 至少 3 类外设功能同时在成品中真实工作（能在演示中逐个指出并触发）。
- 器件清单与实际使用一致（评审时随机抽查 3 个器件，能说清它在电路里起什么作用）。
- 能随口讲清任意一段代码的作用，能说清改一个需求要动哪几个文件。
- 使用说明完整到"另一个人不看代码也能把成品用起来"（评审时请一位同学现场照说明操作验证）。
- `PITFALLS.md` 里至少有 2 条本项目的踩坑记录（现象 + 原因 + 解决办法）。

## 提交要求

- 提交到个人仓库的 `projects/P10-独立选题结课项目/` 目录；在期末评审时当面演示 10 分钟并接受追问。
