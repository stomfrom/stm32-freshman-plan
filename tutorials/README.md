# tutorials/ 手把手教程目录

> 每个项目一份教程文件，**文件名与 `tasks/` 里的任务卡完全对应**（如 `tutorials/P03-GPIO与按键.md` 对应 `tasks/P03-GPIO与按键.md`）。

## 这是什么

`tasks/` 里的任务卡告诉你**要做什么、怎么算过关**；本目录告诉你**具体怎么做**——知识点详解 + 完整操作步骤 + 可复制的代码。

任务卡里每一条任务都带一个「📖 教程」链接，点击直接跳到本目录对应的小节。

## 跳转是怎么实现的

任务卡里的链接形如：

```markdown
- [ ] 1. 配置 GPIOC 为上拉输入… [📖 教程](tutorials/P03-GPIO与按键.md#p03-a1)
```

教程里对应小节用**显式 HTML 锚点**（GitHub 对中文标题的自动锚点不稳定，显式锚点才可靠）：

```markdown
<a id="p03-a1"></a>
### A1 · 配置上拉输入读取按键
```

**锚点命名规则**（全仓库统一，方便脚本校验）：

```
p{项目号}-{档位字母}{序号}     例：p03-a1、p03-b3
```

## 硬件前提

本套教程绑定 **STM32F103C8T6**（最小系统板 / 蓝板），引脚号均按该芯片与常见最小系统板编写。**若你的板子引脚不同，以板子原理图为准**——教程里会标出"这是哪一步的差异"。

| 项目 | 取值 |
|---|---|
| 芯片 | STM32F103C8T6（Cortex-M3，64KB Flash，20KB RAM） |
| 系统时钟 | 72MHz（HSE 8MHz × PLL 9 倍频） |
| 开发环境 | STM32CubeMX 6.x + Keil MDK（或 VS Code + PlatformIO） |
| 库 | HAL 库 |
| 下载调试 | SWD（ST-Link） |
| 板载 LED | **PC13**（常见蓝板），低电平点亮 |
| 板载按键 | **PA0**（常见蓝板，标 KEY 或 WK_UP），按下为高电平 |
