# tutorials/ 手把手教程目录

> 每个项目一份教程文件，**文件名与 `tasks/` 里的任务卡完全对应**（如 `tutorials/P03-GPIO与按键.md` 对应 `tasks/P03-GPIO与按键.md`）。

## 这是什么

`tasks/` 里的任务卡告诉你**要做什么、怎么算过关**；本目录告诉你**具体怎么做**——知识点详解 + 完整操作步骤 + 可复制的代码。

任务卡里每一条任务都带一个「📖 教程」链接，点击直接跳到本目录对应的小节。

## 跳转是怎么实现的

任务卡里的链接形如：

```markdown
- [ ] 1. 配置 PA0 为下拉输入，读取板载按键电平… [📖 教程](../tutorials/P03-GPIO与按键.md#p03-a1)
```

教程里对应小节用**显式 HTML 锚点**（GitHub 对中文标题的自动锚点不稳定，显式锚点才可靠）：

```markdown
<a id="p03-a1"></a>
### A1 · 配置下拉输入读取按键电平
```

**锚点命名规则**（全仓库统一，便于脚本校验）：

```
p{项目号}-{档位字母}{序号}     例：p03-a1、p03-b3
```

**维护规则**：增删任务点时必须同时改三处——① `tasks/` 卡里的条目与链接；② 教程里的 `<a id>` 锚点；③ 本文件「当前进度」表的任务点数。三者不一致会导致链接死掉。

## 硬件前提

本套教程绑定 **STM32F103C8T6**（最小系统板 / 蓝板），引脚号均按该芯片与常见最小系统板编写。**若你的板子引脚不同，以板子原理图为准**——教程里会标出"这是哪一步的差异"。

| 项目 | 取值 |
|---|---|
| 芯片 | STM32F103C8T6（Cortex-M3，64KB Flash，20KB RAM） |
| 系统时钟 | 72MHz（HSE 8MHz × PLL 9 倍频） |
| 开发环境 | STM32CubeMX 6.x + Keil MDK（C99 Mode 必须勾选） |
| 库 | HAL 库 |
| 下载调试 | SWD（**ST-Link V2**，需单独购买，蓝板不自带烧录器） |
| 串口 | **USB-TTL 模块（CH340）** 接 PA9(USART1_TX)/PA10(USART1_RX)，或按板子的板载串口连接 |
| 板载 LED | **PC13**（常见蓝板），**低电平点亮**；PC13 **没有定时器通道**，做 PWM 要外接 LED 到 PA6 |
| 板载按键 | **PA0**（常见蓝板，标 KEY 或 WK_UP），按键另一端接 3.3V，**按下为高电平** → CubeMX 配 **下拉输入（Pull-down）**，外部中断用 **上升沿（Rising）** |

> ⚠️ **上板第一件事：先确认按键与 LED 的极性，别照抄**。不同批次蓝板/key 板差异很大（有的按键接地、按下为低；有的根本没有 PA0 按键）。开课第一周请按下面三步实测，并把结论写进 P01 的 README：
> 1. 用万用表通断档确认按键两端分别接 **3.3V** 还是 **GND**；
> 2. 配 `GPIO_Input`（先不上下拉），串口分别打印"不按 / 按下"的引脚电平；
> 3. 按实测结果决定用**下拉**（按下为高）还是**上拉**（按下为低），并**把后面对高/低电平的所有判断整个反过来**。
>
> 本仓库的 P03/P04 教程按"PA0 + 下拉 + 按下为高 + 上升沿"编写。若你的板子是"按下为低"，只需把这三处一起反过来即可，其余代码不用动。

## 建议使用方式

1. **先看任务卡再看教程**：任务卡给你验收标准，教程给你步骤，别一上来就照着教程抄。
2. **每节做完立刻验证**：教程每节都有「验证方法」，不通过就不要往下走——后面所有步骤都建立在这一步正确的前提上。
3. **卡住时先看本节「常见问题表」**，再看 `hints/PXX-*.md`，最后才是问人。
4. **代码不要整段复制**：先看懂再敲一遍，至少把每行注释改成自己的话。评审时的"必问三题"就照着这个查。
